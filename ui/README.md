# Рупор — интерфейс (Tauri + React)

Фронтенд двух окон: главное (`index.html`) и пилюля (`pill.html`).
Стек: Vite 7, React 18, TypeScript strict, Tailwind CSS 4, Framer Motion, lucide-react,
шрифт Inter Variable (латиница и кириллица, без сети).

## Команды

```bat
npm install
npm run dev          :: dev-сервер http://localhost:1420 (его же открывает tauri dev)
npm run typecheck    :: tsc -b
npm run build        :: tsc -b && vite build → dist/ (index.html + pill.html)
npm run check:i18n   :: ru.json и en.json: паритет ключей, формы множественного числа по Intl.PluralRules
                     :: (ru one/few/many, en one/other), одинаковые подстановки {…}, в en.json нет
                     :: кириллицы; в src/**/*.ts(x) вне src/i18n нет кириллицы в строках и JSX;
                     :: стили и уведомления демо-ядра (mock-data*.json) совпадают с текстами ядра
                     :: (core/rupor/locales). Ядро поменяло текст — `node scripts/check-i18n.mjs --fix`
npm run check:contract -- --port <p> --token <t> --no-mic --quit
                     :: живая сверка ответов/событий ядра с src/lib/types.ts (ядро с --no-hook --no-mutex);
                     :: событие ai_usage — через заглушку Ollama в самом скрипте (без сети, 2 записи
                     :: kind=test по $0 остаются в расходе; --no-ai-usage — пропустить). В конце —
                     :: список того, что в этом прогоне не сверено (ai_balance при ключе в Credential
                     :: Manager, события, которые бывают только при записи с хоткея). Папка модели:
                     :: model_dir в настройках и setup_status, model_recommend (может спросить у
                     :: Hugging Face размеры моделей), model_dir_set — «та же папка» и ошибки; смена
                     :: папки (во временную и обратно) — только на ядре первого запуска без модели;
                     :: перенос модели не запускается: это гигабайты
..\build.cmd       :: сборка установщика (ядро PyInstaller + Tauri; без ядра release-сборка падает)
```

## Проверка в обычном браузере

- `?mock=1&lang=en` (или `lang=ru`) — «язык Windows» демо-ядра: при `language: "system"` интерфейс
  на нём, и демо-данные (история, словарь, сниппеты — `mock-data.en.json` / `mock-data.json`)
  тоже. Без `lang` — по `navigator.language`. Сообщения демо-ядра (notice, ошибки, стили) идут на
  текущем языке интерфейса, как у настоящего ядра; язык переключается в «Настройки → Общие».
  Работает и для `pill.html`.
- `http://localhost:1420/?mock=1` — демо-режим: фейковое ядро со всеми командами и событиями
  (история за 30 дней, словарь, сниппеты, статистика, имитация записи и уровня микрофона).
  Кнопка «Демо: имитация диктовки» внизу меню запускает запись → распознавание → результат,
  а через ~3 с — «правку» для словаря по режиму `learn_mode` (см. ниже).
- Папка модели («Настройки → Диктовка → Папка модели», шаг «Видеокарта и модель» мастера):
  демо-ядро помнит, какая модель в какой папке; в кэше Hugging Face по умолчанию
  (`C:\Users\Demo\.cache\huggingface\hub`) лежат все модели. Новая папка со скачанной моделью —
  окно «Перенести модель?»: на тот же диск — мгновенно, на другой — с прогрессом; в папку с
  `full` в пути (`E:\full-disk\models`) перенос падает «не хватает места». Относительный путь —
  ошибка валидатора. «Обзор…» (системный диалог) есть только в приложении.
- `?mock=1&first_run=1&gpu=0` — мастер на компьютере без видеокарты NVIDIA: `cuda_check` без GPU,
  `model_recommend` советует `small` на процессоре (без `gpu=0` — RTX 3060 Ti и `large-v3-turbo`);
  рекомендация подставляется сама, пока модель не скачана.
- `?mock=1&learn=1` (или `learn=suggest`, `learn=off`) — режим `learn_mode` при старте и через
  ~1 с уведомление «В словарь добавлено: «ноушен» → Notion» с кнопкой «Отменить» (в режиме
  suggest — «Добавить в словарь: …?» с кнопкой «Добавить»). Для пилюли: `pill.html?mock=1&demo=0&learn=1`.
- `?mock=1&first_run=1` — мастер первого запуска (модель «не скачана», `state=error`, ключа нет).
- `?mock=1&no_model=1` — мастер пройден, а модели нет: баннер «Модель распознавания не скачана»
  с кнопкой «Скачать модель» и прогрессом загрузки.
- `pill.html?mock=1` — пилюля крутит демо-цикл: запись, «В словарь добавлено», «без рук»,
  рассылка в RDP (с адресатами «→ srv-analytics-02, srv-etl-01»), ошибка с кнопкой
  «Перезапустить от администратора», командный режим, «ИИ не ответил», ошибка вставки.
  `&demo=0` — без цикла. Тексты уведомлений — настоящие тексты ядра (с длинным заголовком окна).
- `?mock=1&ai=0` — ИИ выключен: на Главной карточка «ИИ-очистка выключена» с «Включить»,
  строки расхода в трее нет (`ai_line: null`).
- `?mock=1&low_balance=1` — баланс OpenRouter $0.62 и предупреждение «меньше $1».
- `?mock=1&rdp=0` — нет открытых RDP-окон; `&rdp=none` — окна есть, ни одно не отмечено.
- `?scene=broadcast` (запись с рассылкой в 2 сессии, 60 с), `broadcast_all` (в 4 — «и ещё 2»),
  `broadcast_none` (сессии не выбраны → через 4 с notice «Не выбраны RDP-сессии для рассылки»
  с кнопкой «Выбрать сессии») — для `pill.html` и главного окна (тост).
- `?scene=notice_admin` (окно от администратора — самый длинный текст с кнопкой), `notice_insert`
  (ошибка вставки — самый длинный без кнопки), `notice_ai` — одно уведомление ядра через 0,5 с:
  проверка вёрстки пилюли `pill.html?mock=1&demo=0&lang=en&scene=notice_admin` на 360×96.
- Адреса страниц: `#/dictionary/vocab` — «Словарь → Частые слова»,
  `#/settings/insert/sessions` — «Вставка», прокрутка к «Сессиям для рассылки» с подсветкой
  (сюда ведёт notice с `action: "open_settings_insert"`).
- `?port=<порт>&token=<токен>` — подключение к настоящему ядру, запущенному
  `python -m rupor --sidecar --ws-port <порт> --token <токен> --no-hook --no-mutex`.

Скриншоты для README (`docs/screenshots/en/`, `docs/screenshots/ru/`) снимаются в демо-режиме
со статической сборки (`npm run build && npm run preview`, порт 1421) с `?mock=1&lang=en|ru`:
адреса, размеры и порядок съёмки — в [docs/TESTING.md, «Скриншоты для README»](../docs/TESTING.md#скриншоты-для-readme).

| `src/components/Duck.tsx` | «Настройки → Диктовка → Звук компьютера во время записи» (`duck_mode`, `duck_level`) |

Трей обслуживает главное окно: на каждое событие `state` зовёт `update_tray`, действия
`tray-action` (`pause`, `mode:*`, `style:*`, `last_insert`, `rdp:<key>`) выполняет через WS.
В `update_tray` всегда уходят ещё три поля — `labels` (см. «Язык интерфейса») и:
- `ai_line` — «ИИ: сегодня $0.03 · баланс $12.34» (без баланса — «ИИ: сегодня $0.03»), `null`
  при выключенном ИИ. «Сегодня» — из `ai_usage_stats` (сразу из `today_cost_usd` события
  `ai_usage`, затем перечитывается; ещё — при открытии Главной и «Настройки → ИИ → Расход» и
  после смены даты: раз в минуту окно сверяет дату последней загрузки, так что в полночь
  «сегодня» обнуляется без вызова ИИ).
  Баланс OpenRouter (`src/lib/aiUsage.ts`, `balanceMode`) — только если Рупор в него ходит:
  очистка через OpenRouter — `ai_balance` при подключении, раз в 15 мин и через 3 с после
  платного вызова; через OpenRouter только командный режим — лишь после платного вызова (ответ
  из кэша ядра, которое само обновило баланс); Ollama/Anthropic/Claude Code — не запрашивается
  и не показывается (ни в трее, ни на Главной, ни в «Расходе»). Без `force`: у ядра свой
  5-минутный кэш; `force` — только кнопка «Обновить» и смена ключа.
- `rdp` — `[{key, title, included}]` открытых RDP-сессий для подменю «Рассылка в RDP ▸»; окна
  RDP появляются без событий ядра, поэтому главное окно перечитывает `rdp_windows` раз в 15 с,
  после `rdp_toggle` и после смены `broadcast_targets` (событие `settings`). Пункт меню
  `rdp:<key>` → `rdp_toggle {key, included: !included}` → трей и «Настройки → Вставка» обновятся.

Вне Tauri (демо в браузере) трея нет: последнее содержимое меню лежит в `window.__ruporTray`,
а `window.__ruporTrayAction("rdp:srv-etl-01")` имитирует пункт меню — так проверяется связка
в headless-браузере.

Рассылка — белый список: текст уходит только в открытые и отмеченные сессии. Ключ сессии —
имя сервера из заголовка mstsc, для других клиентов — заголовок. В «Настройки → Вставка →
Сессии для рассылки» ключ крупно, заголовок мельче; отмеченные, но закрытые сейчас сессии видны
с пометкой «Не открыта» (их можно снять). Пилюля во время записи с рассылкой показывает
адресатов из `recording.targets` («→ srv-analytics, dev-box и ещё 2»); если рассылку включили
модификатором уже во время записи — берёт отмеченные из `rdp_windows`.

Запись хоткея в настройках и мастере (`HotkeyCapture`, `ChordCapture`) на время записи
ставит ядро на паузу (`src/lib/capture.ts`): хук ядра видит клавиши раньше WebView, и без
паузы нажатие текущего «Вставить последнее» вставило бы текст в чужое окно. Пауза снимается,
когда запись закончилась (или окно закрыли), и только если до записи её не было.

Уведомления ядра (`notice`): пилюля показывает warn/error поверх всего, кроме записи, а info
(«Отправлено в 3 RDP-сессий») — нейтрально и после «Вставлено». Если пилюля выключена
(`pill_enabled=false`), на время warn/error она всё равно появляется: главное окно обычно
скрыто в трее, и кнопку «Перезапустить от администратора» иначе никто не увидит.
Тексты ядра бывают по 150–180 символов, а окно пилюли — 360×96: уведомление с кнопкой — текст
на всю ширину в 3 строки, значок слева от кнопки; без кнопки — до 4 строк рядом со значком.
Что не влезло, видно во всплывающей подсказке (`title`) и в тосте главного окна.

Словарь учится на правках (`learn_mode`: `auto` | `suggest` | `off`). Ядро ~60 с после вставки
следит за полем и присылает `notice` с `level="info"`, `toast=true`, `data={term, variant, id, created}`:
- `action="dict_undo"` — правка уже в словаре. Пилюля показывает текст ядра («В словарь добавлено:
  «метабейс» → Metabase») с кнопкой «Отменить» → `dict_learn_undo(data)`;
- `action="dict_add"` — режим suggest, кнопка «Добавить» → `dict_learn_accept({term, variant})`.

Уведомление нейтральное (иконка словаря, без красной подсветки), висит ~6 с (под курсором — дольше),
после нажатия — «Отменено»/«Добавлено» и пилюля прячется. Несколько правок подряд показываются
по очереди; спрятанное за записью ждёт до 2 мин. Кнопка не берёт фокус и не запускает ни
диктовку, ни перетаскивание. При `pill_enabled=false` пилюля на время уведомления всё равно
появляется — пользователь должен видеть, что попало в словарь. Главное окно показывает тот же
тост с той же кнопкой, а страница «Словарь» перечитывает список. Нажатие в одном окне
передаётся остальным через `BroadcastChannel("rupor-learn")` (`src/lib/learn.ts`): второе окно
не отправит отмену повторно. Отметка «уже нажато» относится к одному уведомлению: ядро может
прислать такое же ещё раз (термин удалили на странице «Словарь» и снова так же исправили), и каждое
пришедшее уведомление снимает старую отметку (`learnNoticeArrived`), если нажатие было не в
последние 3 с (тогда это то же уведомление, просто дошедшее позже). Режим выбирается на странице «Словарь» (карточка «Учиться на ваших
правках» с примером пилюли) и в «Настройки → Диктовка».

Звук компьютера во время записи (`src/components/Duck.tsx`, «Настройки → Диктовка», адрес
`#/settings/dictation`): `duck_mode` — «Не трогать» (`off`) / «Приглушать» (`duck`, по умолчанию) /
«Выключать» (`mute`); для «Приглушать» — ползунок `duck_level` 0–100 % с шагом 5 (по умолчанию 15)
и пример в подсказке («музыка на 80 % зазвучит на 12 %»). В ядро уходит только отпущенное
значение ползунка. Само приглушение (аудиосессии Core Audio, возврат, `duck.json`) — забота ядра,
интерфейс только меняет настройки; в мастере строки нет. Мок хранит оба поля, звук не трогает.

Живой уровень микрофона (`mic_monitor`) включён, только пока окно видно: в Tauri скрытие
в трей не меняет `document.visibilityState`, поэтому `watchWindowShown` раз в секунду
спрашивает `isVisible`/`isMinimized` у окна.

## Язык интерфейса

Русский и английский (`src/i18n/ru.json`, `en.json`), переключение на лету, без перезагрузки окна.
Какой язык показывать (`src/i18n/index.ts`, `syncLocale`):

1. `settings.language` — `"ru"` или `"en"`, если пользователь выбрал явно;
2. `"system"` (по умолчанию) — `State.ui_language`: ядро разрешает его по языку интерфейса Windows
   (ru/be/uk/kk → русский, иначе английский);
3. до `hello` — язык прошлого запуска (`localStorage["rupor.locale"]`), иначе `navigator.language`
   по тому же правилу; в демо и проверках — `?lang=en|ru`.

`setLocale` меняет словарь, `<html lang>`, правила множественного числа и форматтеры `Intl`;
корень окна (`App`, `Pill`) подписан через `useLocale()` и перерисовывается целиком. Если
что-то посчитано в `useMemo` с `t()`/форматированием, `locale` — в его зависимостях. Названия и
описания стилей (`styles_list`), тексты `notice` и ошибок команд приходят от ядра уже на языке
интерфейса; при смене `ui_language` окно перечитывает `styles_list`. Даты — «Сегодня / Today»,
«24 сентября / September 24», числа — «48 214 / 48,214», множественное число — `Intl.PluralRules`;
доллары в обоих языках как в кабинете OpenRouter (`$12.34`). Английский формат дат и времени — по
основному языку системы (`englishTag` в `src/i18n/index.ts`): en-GB/en-AU/en-US — как есть;
русская (и любая другая) Windows с выбранным English — английский для её региона, если у `Intl`
он есть (de-DE → en-DE), иначе по часам системы: 24-часовые — en-GB («21:05», «24 Sept»),
12-часовые — en-US («9:05 PM», «Sep 24»). В тексте фраз язык называется на языке интерфейса
(`languageName`: «сейчас русский» / "currently Russian"), самоназвания — только в выборе языка.

- «Настройки → Общие → Язык»: «Язык интерфейса» (Системный / Русский / English — названия языков
  всегда на своём языке) и «Язык диктовки» (`dictation_language`: Авто / Русский / English).
- Мастер первого запуска начинается с выбора языка: две карточки, на карточке языка Windows —
  отметка «Язык Windows». Язык Windows сохраняется как `"system"`, другой — явным выбором.
  Выбран не язык Windows (или язык диктовки уже закреплён) — под карточками «Язык диктовки»
  (Авто / Русский / English): в режиме «Авто» приоритет у языка интерфейса, и русская речь на
  русской Windows с английским интерфейсом иначе молча стала бы «английской» при неуверенном
  определении.
- Заголовок окна — `t("app.name")` («Рупор» / "Rupor") через `setTitle` (и `document.title`),
  у пилюли — `pill.windowTitle`.
- Трей: в `update_tray` всегда уходит `labels` — все строки меню и подсказки значка на языке
  интерфейса плюс `lang` (на нём оболочка берёт встроенные строки для недостающих ключей и
  пишет свои сообщения). До подключения окна оболочка показывает встроенные строки по языку Windows.
- Новые строки — сразу в оба файла; `npm run check:i18n` ловит расхождения. В английском —
  естественный язык продукта, не калька: «Hold to talk», «Paste last», «Keystrokes».
  Пилюля по-английски — «indicator», способ вставки — «Insert method», ИИ-обработка — «AI cleanup»
  (и статус «AI cleanup…» — в боковой панели, пилюле и трее). Подсказки клавиш — «Esc to cancel»,
  «Ctrl+Enter to save · Esc to cancel», а не русское «Esc — отмена».

Проверка вёрстки на обоих языках — headless-скриншоты демо-режима (`?mock=1&lang=en|ru`) на
ширине окна 1080 и минимальной 900 px и пилюли 360×96: без горизонтальной прокрутки, без
переносов в кнопках, вкладках и сегментах, в английском — без кириллицы.
