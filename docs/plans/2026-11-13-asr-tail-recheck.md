# Перепроверка окончания распознавания

Согласованный подход: подозрительная служебная фраза служит сигналом для одного
прохода без подсказки, но сама по себе не удаляется. При сомнении остаётся первый
результат. Существующая перепроверка повторов и мусора использует тот же проход.
Первый текст сохраняется в метаданных сохранённой аудиозаписи.

Из upstream MR #6 переносится дописывание 300 мс после отпускания клавиши:
окно назначения фиксируется до ожидания, звук восстанавливается после него.
Ожидание ограничено и при пропавшем микрофоне.

Порядок: регрессионные тесты и проверка их падения; реализация ASR и метаданных;
реализация аудиохвоста и интеграция; полный pytest, mypy, сборка UI; независимый
review. Существующие доработки форка и версия релиза сохраняются.

Выполнено: 1469 pytest-тестов прошли, 3 пропущены (включены нативные проверки NSIS);
mypy — 32 файла без ошибок; сборка UI и проверка 1048 ключей переводов успешны.
Независимый review выявил гонку с мастером проверки микрофона во время хвоста:
исправлена ограниченной блокировкой жизненного цикла записи и проверена тестом с
синхронизированными потоками; повторный review подтвердил исправление.
Качество распознавания на реальных пользовательских диктовках отдельно не измерялось.
