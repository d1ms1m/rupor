# Rupor 0.6.0 — d1ms1m

Сборка форка [d1ms1m/rupor](https://github.com/d1ms1m/rupor) на основе upstream
[listapad2024/rupor 0.6.0](https://github.com/listapad2024/rupor/commit/6c25c66a255343bc9e4cf9d9dd034885c609b244).

## Отличия от upstream 0.6.0

- **OpenAI-совместимый API** для ИИ-очистки и командного режима: свой базовый URL, модель,
  необязательный ключ и дополнительные JSON-параметры. Настройки режимов выбираются независимо;
  параметры подключения общие. Облачная цепочка OpenRouter/Anthropic работает отдельно.
- **Учёт расходов OpenAI API:** ручные тарифы входа, выхода и кэшированных токенов, приоритет
  стоимости от сервера, отметки расчётной и неизвестной стоимости. Исторические суммы сохраняются.
- **Исправления интерфейса:** выпадающие списки видны и нажимаются внутри модальных окон;
  экспорт пустых списков сниппетов и словаря отключён; устранено обрезание подсветки карточек и фокуса.
- **Совместимое обновление:** схема SQLite 5 принимает прежние базы форка и upstream, сохраняет
  расходы и происхождение стоимости. Миграция настроек сохраняет OpenAI-провайдер и приоритет
  облачного провайдера команд.
- **Удаление ключей:** при выборе «Удалить данные приложения» деинсталлятор очищает все
  записи `Rupor/*`, включая OpenAI API и дополнительные ключи цепочки. При обновлении и удалении
  без этой галочки ключи сохраняются.
- **Проверки и документация:** регрессии совместимости, настройка Mypy для динамических COM-интерфейсов,
  актуальные README и перечни зависимостей сборки.

## Возможности upstream, включённые в сборку

- Несколько ключей OpenRouter/Anthropic по приоритету, переключение при ошибке и баланс по ключу.
- Сохранение последних записей голоса, прослушивание и повторное распознавание из истории.
- Исправление раскладки выделенного текста через Shift+Pause.
- Исправления длинных диктовок, буфера обмена, хоткеев, настроек, микрофона и словаря.

Изменения из открытых upstream PR #6 и #13 (0.6.1) в этот релиз не включены.

## Установка и проверка загрузки

Скачайте `Rupor_0.6.0_d1ms1m_x64-setup.exe` и установите поверх прежней версии.
Настройки, история, словарь, ключи и скачанная модель сохраняются при обновлении.
Имя приложения и каталог установки прежние; `d1ms1m` в имени релиза и файла обозначает этот форк.

Контрольная сумма установщика — в `SHA256SUMS.txt`. В PowerShell:

```powershell
Get-FileHash .\Rupor_0.6.0_d1ms1m_x64-setup.exe -Algorithm SHA256
```

Windows 10/11 x64. Модель и CUDA скачиваются отдельно при первом запуске; в установщик не включены.
Установщик без цифровой подписи. Исходный проект и его авторство сохранены, лицензия MIT.
