# Rupor 0.6.2 — d1ms1m

Новый выпуск форка [d1ms1m/rupor](https://github.com/d1ms1m/rupor).
Включает все изменения 0.6.1 — d1ms1m и выборочную перепроверку окончаний Whisper.

## Что изменилось относительно 0.6.1

- **Перепроверка подозрительных окончаний без подсказки.** Известная служебная приписка
  в конце диктовки служит сигналом для проверки звука. Фраза не удаляется автоматически
  по словарю: новый результат принимается, только если он подтверждает текст перед
  припиской и не содержит признаков мусора, повторов или низкой уверенности.
  При расхождении результатов или ошибке этой перепроверки остаётся первый ответ.
- **Без лишних проходов.** Проверка окончания использует тот же единственный дополнительный
  проход, что и существующие проверки повторов и мусора. Третий проход не запускается.
  Если первый ответ уже уверенно получен без подсказки с температурой 0, одно лишь
  подозрительное окончание не запускает повторное распознавание.
- **Сохранение исходного текста.** Первый ответ ASR сохраняется в JSON-метаданных аудиозаписи
  (`asr_original_text`). Ручное перераспознавание его не перезаписывает. Настройки хранения
  записей действуют как прежде: при отключённом сохранении отдельного хранения текста нет.
- **Последний звук не обрезается при отпускании клавиши.** Из [upstream MR #6](https://github.com/listapad2024/rupor/pull/6)
  адаптировано дописывание 300 мс аудио. При пропавшем микрофоне ожидание ограничено 500 мс;
  отмена и выброс завершают запись сразу. Окно вставки фиксируется до ожидания.
- **Звук компьютера остаётся приглушённым до окончания записи** и восстанавливается также
  при ошибке остановки микрофона. Исправлена гонка с мастером проверки микрофона: новая
  проверочная запись не может заменить буфер завершающейся диктовки.

Автоматическое обрезание фраз по словарю из MR #6 не переносилось.
Существующая обработка зацикливаний и мусора из MR #13 сохранена.

## Сохранённые отличия форка от upstream

- OpenAI-совместимый провайдер для ИИ-очистки и команд: свой URL и модель, необязательный
  ключ, дополнительные JSON-параметры и ручные тарифы с учётом кэшированных токенов.
  Сохранены серверная стоимость, признаки расчётной/неизвестной стоимости и история расходов.
- Исправления выпадающих списков в модальных окнах, экспорта пустых списков и подсветки карточек.
- Совместимая схема SQLite 5 и миграции настроек, сохраняющие доработки форка и прежние данные.
- Деинсталлятор удаляет все ключи `Rupor/*`, включая OpenAI API, при выборе «Удалить данные
  приложения»; обновление и удаление без этой галочки сохраняют ключи.
- Сохранены остальные возможности 0.6.1: цепочка ключей OpenRouter/Anthropic, записи голоса,
  перераспознавание из ленты истории, исправление раскладки и доработки словаря.

## Установка

Скачайте `Rupor_0.6.2_d1ms1m_x64-setup.exe` и установите поверх прежней версии.
Настройки, история, словарь, ключи и скачанные модели сохраняются при обновлении.
Подпись `d1ms1m` обозначает сборку форка; цифровой подписи у установщика нет.
Windows 10/11 x64; модель и CUDA скачиваются отдельно и в установщик не включены.

Вложения: установщик, `BUILD-INFO.txt` с версией и исходным коммитом,
`SHA256SUMS.txt` с контрольными суммами. Проверить установщик в PowerShell:

```powershell
Get-FileHash .\Rupor_0.6.2_d1ms1m_x64-setup.exe -Algorithm SHA256
```
