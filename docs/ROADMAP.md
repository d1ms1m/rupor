## 4. Личный словарь частот и контекст окна (подсказка для Whisper) — ядро сделано (27.09.2026)
Ядро: `core/rupor/vocab.py` + частотные списки `core/rupor/data/common_{ru,en}.txt`; таблицы
`vocab`/`vocab_excluded` (схема базы 3, пересчёт по истории при миграции и при смене правил),
инкрементально при записи/удалении истории; подсказка «контекст окна + термины + частые
слова процесса + общие» ≤ 200 токенов, частых ≤ 60 (слабых — ≤ 20, после сильных);
контекст — `uia.caret_context` в фоне при нажатии, ≤ 300 мс; частые термины и имена — в
промпт ИИ-очистки; WS `vocab_list` / `vocab_exclude`; настройки `vocab_enabled`,
`context_enabled`. UI («Ваши частые слова», переключатели) — в интерфейсе.

Исправлено по ревью (27.09.2026):
- производительность на большой истории (синтетика: 20 000 записей, ≈ 95 тыс. строк vocab):
  срок хранения, удаляющий 15 тыс. записей, — 56 с под замком базы → 1,7 с (тексты
  разбираются до замка, под замком — одно вычитание и один `DELETE`); подсказка Whisper +
  термины ИИ перед каждой диктовкой — 0,7 + 0,7 с → 0 мс (топ слов считается в SQL, кэш общий
  и после диктовки обновляется в фоне; холодный кэш — ≈ 90 мс); `vocab_list` — 0,65 с → 0 мс;
- пересборка частот после миграции или новой версии отбора — в фоне после старта: порт ядра
  с базой версии 2 и 20 000 записей открывается через 0,6 с (раньше +5 с), пересборка — 3 с
  в фоне; битый UTF-8 в истории больше не ломает запуск (раньше — миграцию при каждом старте);
- длина подсказки считается токенизатором модели (`Recognizer.token_counter`), без него —
  оценкой, которая не меньше настоящего числа токенов (кириллица 1,45 симв./токен вместо 3);
  контекст окна — ≤ 100 токенов; раньше подсказка с контекстом доходила до 261 токена, и
  faster-whisper срезал её начало (контекст);
- падежные формы сливаются по основе («Тимуру», «Тимура», «Тимуром» → «Тимур»), исключение
  действует на все формы; бытовые формы глаголов и слова с приставкой («можешь», «лежат»,
  «подскажи», «передай») — общие; «Wi-Fi», «Яндекс.Go» — целиком; «Summer2024» и похожее на
  пароль — не берутся; «Очистить всё» стирает и исключения, исключённые слова видны в списке
  и без частот.

Замер `tools/wer_bench.py --compare --context --repeat 1` (27.09.2026, после исправлений,

## 5. Приглушать звук компьютера во время диктовки — ядро сделано (27.09.2026)
Ядро: `core/rupor/duck.py` (свои описания интерфейсов Core Audio на comtypes — pycaw не
понадобился: он тянет psutil, а генерировать в сборке нечего), поток `rupor-duck`, настройки
`duck_mode`/`duck_level`, приглушение на подтверждении записи (и проверочной записи мастера),
возврат на всех путях её окончания и при смене настроек, переопрос раз в 0,5 с (заигравшие
сессии), «пользователь поменял сам — не трогаем», `duck.json` с записью ДО изменения и
возвратом при старте; запись о закрытом приложении ждёт (до 7 дней) его нового экземпляра —
Windows отдаёт ему запомненную приглушённую громкость. Самопроверка сборки:
«Core Audio: ok, сессий N, устройств вывода D» в `--uia-selftest`, `packaging/verify_core.py`
её требует; сборка PyInstaller проверена. Контракт — `docs/ARCHITECTURE.md` («Звук компьютера
во время записи»). Тесты: `tests/test_duck.py` (логика на фейковых сессиях + настоящий Core
Audio только на собственной сессии: отдельный процесс играет тишину), `tests/test_duck_engine.py`.

Исправлено после ревью (27.09.2026, ядро):
- громкость и беззвук ведутся порознь (`vol_ours`/`mute_ours` в `duck.json`): пользователь
  выключил звук приглушённой программы — громкость всё равно возвращается; подвинул громкость
  выключенной — беззвук всё равно снимается;
- смена устройства по умолчанию посреди записи: приглушаются сессии на устройствах по
  умолчанию (eConsole, eMultimedia, eCommunications), возвращаются — на любом активном
  устройстве вывода (раньше сессия на прежнем устройстве оставалась приглушённой);
- `duck.json` переписывается только при изменении записей (раньше — каждые 3 с, пока была
  ожидающая запись);
- смена `duck_mode`/`duck_level` посреди записи не приглушает снова сессии, которые
  пользователь поменял сам; уровень в режиме «выключать» ни на что не влияет;
- выход: WS `quit` сразу ставит возврат звука, `shutdown` — первым делом; конец сеанса
  Windows ядро ловит скрытым окном (WM_QUERYENDSESSION → вернуть звук до WM_ENDSESSION);
- `tools/ws_smoke.py` пишет во временные настройки `"duck_mode": "off"`, `tools/e2e.py` —
  `duck_mode="off"` и приглушение без Core Audio с `duck.json` во временной папке (звук и
  `duck.json` пользователя не трогаются).

Интерфейс: «Настройки → Диктовка → Звук компьютера во время записи» (`ui/src/components/Duck.tsx`:
«Не трогать» / «Приглушать» + ползунок `duck_level` / «Выключать», пояснение; `types.ts`,
`mock.ts`, `ru.json`).

Оболочка Tauri (27.09.2026, финальная сборка): «Выход» (`quit_app`, трей, `RunEvent::Exit`) больше не
снимает ядро сразу — `Supervisor::shutdown` шлёт готовому ядру WS `quit` (свой минимальный
клиент в `sidecar.rs`), ждёт выхода процесса до 2,5 с (обычно ~0,4 с) и только потом `kill`:
выход посреди записи возвращает громкость сразу. Тесты: `shutdown_asks_core_to_quit` (поддельное
ядро в режиме ws), `send_quit_fails_fast_without_websocket`, `base64_and_ws_frame`; настоящее
ядро — `real_core_smoke` (ignored, запускать с временными APPDATA/LOCALAPPDATA).

Исходный план:
- Настройка `duck_mode`: "off" | "duck" (приглушить до `duck_level`, по умолчанию 15 %) |
  "mute" (выключить); по умолчанию "duck". `duck_level: int 0–100`.
- Уровень аудиосессий Windows (Core Audio: IAudioSessionManager2 → ISimpleAudioVolume на
  устройстве вывода по умолчанию, через comtypes; можно pycaw), а не общий уровень устройства:
  сессии процесса ядра Рупора (звуки начала/конца записи) не трогать.
- Приглушать при подтверждении записи (после звука начала) — в т.ч. «без рук»; возвращать
  при стопе/отмене/выбросе/лимите/паузе/выходе. Возвращать только то, что меняли сами, и к
  исходному значению; сессии, которые пользователь сам поменял во время записи, не трогать.
  Сессии, появившиеся во время записи, тоже приглушать.
- Защита от «залипшего» беззвука: изменённые сессии записываются в `%APPDATA%\Rupor\duck.json`;
  при старте ядра — восстановить всё, что там осталось (падение, выключение).
- RDP: звук удалённой машины играет через mstsc — приглушается как обычная сессия.
- UI: «Настройки → Диктовка → Звук компьютера во время записи» (выкл / приглушать / выключать)
  + ползунок уровня; строка в мастере не нужна.
